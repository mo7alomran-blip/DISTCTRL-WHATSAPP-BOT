# DistCtrl WhatsApp Bot (احتياطي)

بوت واتساب ذاتي الاستضافة (مكتبة [Baileys](https://github.com/WhiskeySockets/Baileys) — تتصل بواتساب ويب مباشرة
بدون أي بوابة SaaS خارجية). **قناة احتياطية/موازية** لبوابة Hermosa المستخدمة حاليًا بـDistCtrl، مو بديل لها.

## ⚠️ تنبيه مهم قبل الاستخدام

هذي مكتبة غير رسمية (unofficial) — تتصل بواتساب بنفس طريقة واتساب ويب، وليست جزء من واتساب Business API
الرسمي. فيه احتمال (منخفض لكن حقيقي) إن واتساب يحظر الرقم المرتبط لو استُخدم بحجم إرسال كبير أو بنمط يشبه
السبام. مناسب كقناة احتياطية بحجم استخدام قليل (لما Hermosa تنقطع)، مو للإرسال الجماعي المستمر.

## النشر على Railway

1. أنشئ مشروع/خدمة جديدة بـRailway، اربطها بهذا المستودع على GitHub (Deploy from GitHub repo) — أي
   push جديد بينشر تلقائيًا.
2. **مهم جدًا**: أضف **Volume** بإعدادات الخدمة، مثبّت على المسار `/app/auth_info` (أو أي مسار، بس اضبط
   متغير البيئة `AUTH_DIR` عليه نفسه). بدون هذا، أي إعادة نشر (redeploy) تفقد الربط بالكامل وتحتاج مسح QR
   من جديد كل مرة.
3. أضف متغيرات البيئة:
   - `API_KEY` — مفتاح سري تختاره أنت (أي نص عشوائي طويل)، يُستخدم لحماية `/send` من أي استخدام غير مصرّح.
   - `AUTH_DIR` — مسار الـVolume اللي ضبطته بالخطوة 2 (مثلاً `/app/auth_info`).
4. بعد النشر، افتح رابط الخدمة العام (Railway يعطيك رابط تلقائي زي `xxx.up.railway.app`) من متصفح جوالك،
   وامسح كود QR الظاهر من واتساب ← الأجهزة المرتبطة ← ربط جهاز.
5. بعد الربط، الصفحة تبين "✅ واتساب متصل".

## الاستخدام (API)

```
POST /send
Headers: x-api-key: <API_KEY>
Body: { "to": "0501234567", "message": "نص الرسالة" }
```

`GET /status` يرجّع `{"status": "connected" | "qr_pending" | "disconnected" | "starting"}`.
